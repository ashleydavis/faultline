# An `if` with no `else`

The false side of this `if` carries no annotation, and needs none. The run counts how often the function said it was entered against how often the branch said it was taken, and a function entered more often than the branch fired is one that did not take it.

Writing an `else` holding nothing but an annotation, which is what this used to need, said nothing the two lines already there did not.
