# A run that ends below a hundred per cent

One branch turns on a value nothing the run makes up ever produces, so the last line reads less than 100% and the run exits non-zero. The example that reaches every path is the other end of the same number.

Returns `error.SimCoveragePathsUnticked`, and the run would return `error.SimCoverageIncomplete` if every remaining path were ticked while the percentage stayed below a hundred.
